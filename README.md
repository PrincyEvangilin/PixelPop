# 🎨 PixelPop

Create pixel art, unleash your creativity, and download your artwork as PNG! ✨

### ✨ Features
- 🖌️ Draw, erase, fill, and pick colours
- 🌈 24 colours + custom colour picker
- 🧩 8×8, 16×16, and 32×32 grids
- 🪞 Mirror drawing mode
- ↩️ Undo and redo
- 📥 Download artwork as PNG

### 🛠️ Built With
HTML • CSS • JavaScript

### 🚀 Run Locally
1. Clone this repository.
2. Open `index.html` in your browser.

⭐ *Every pixel tells a story!*
